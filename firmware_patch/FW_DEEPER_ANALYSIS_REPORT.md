## Section 11: NVMC Register Pattern Search

NVMC registers for flash operations:
- CONFIG (offset 0x504): 0=ReadOnly, 1=WriteEnable, 2=EraseEnable
- ERASEPAGE (offset 0x508): Write page address to erase
- ERASEALL (offset 0x50C): Write 1 to erase all
- ERASEUICR (offset 0x514): Write 1 to erase UICR
- READY (offset 0x400): Read 1 when operation complete

### No NVMC references found in literal pools

This strongly suggests the application firmware does NOT have direct flash write capability.
Flash operations are handled exclusively by MCUboot (which runs in a different partition).

### Search for NVMC CONFIG magic values

If any code writes to NVMC_CONFIG, it would need to set values 1 (WEN) or 2 (EEN).
These are too common as immediate values to be useful as indicators alone.

   we only need to get our image into the secondary slot
